## About

A structured collection of Design and Analysis of Algorithms laboratory work, with an emphasis on correct implementations, explicit complexity measurement, reproducible experiments, and GitHub-friendly visualizations.

## Labs

| Lab | Focus | Status |
|---:|---|:---:|
| [Lab 01](lab1/) | Growth, experiments, and introductory analysis | ✅ |
| [Lab 02](lab2/) | Algorithm comparison and experimental analysis | ✅ |
| [Lab 03](lab3/) | Divide & conquer, advanced searching, matrix algorithms, loop invariants | ✅ |

## Lab 03 highlights

- Binary vs ternary search with probe-count validation
- Defective-coin search using logarithmic balance-scale operations
- D&C min/max within the `3n/2` comparison bound
- Strassen matrix multiplication with classical cross-check
- Special recursive matrix multiplication in `Theta(n^2)`
- Selection-sort loop invariant, proof, and best/worst-case validation
