Pseudocode:
SELECTION-SORT(A, n)
  for i = 1 to n-1
      min = i
      for j = i+1 to n
          if A[j] < A[min]
              min = j
      exchange A[i] and A[min]

Loop invariant:
At the start of each outer-loop iteration i, A[1..i-1]
contains the i-1 smallest original elements in sorted order.
Initialization: before i=1 the prefix is empty, so the claim is true.
Maintenance   : selecting the minimum of A[i..n] and placing it at A[i]
                extends the sorted-smallest prefix by one element.
Termination   : after i=n-1, the first n-1 positions are correct; the
                last remaining element must be the largest.
