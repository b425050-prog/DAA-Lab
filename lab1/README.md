## Reproducing one question

For Q-1 to Q-4, open the required question folder and run its executable:

```text
program_name.exe
```

The executable regenerates the data, sends its embedded plotting commands to GNUPlot, creates the SVG and opens it automatically. No external `.plt` file or plotting folder is required. GNUPlot must be installed and available in `PATH`. The exact executable and output names are listed in that folder's README.
